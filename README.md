# E-Commerce Sales & Customer Analytics Dashboard

## Dashboard Preview

![E-Commerce Dashboard](Dashboard_Screenshot.png)

## Project Overview

This project analyzes e-commerce sales and customer data using Microsoft Excel.

## Key KPIs

- Total Sales
- Total Orders
- Total Customers
- Units Sold
- Total Profit
- Return Rate
- Average Order Value
- Profit Margin

## Dashboard Analysis

- Monthly Sales & Profit
- Sales & Profit by Category
- Top 10 Best Products
- Bottom 10 Products
- Top 10 Customers
- Sales by City
- Discount vs Profitability
- Sales by Payment Method
- Sales by Channel

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas
- Data Analysis
